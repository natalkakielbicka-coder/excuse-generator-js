# Generator wymówek programisty

Edukacyjna aplikacja napisana w HTML, CSS i czystym JavaScript.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce albo uruchom projekt przez rozszerzenie Live Server w VS Code.

## Plan nauki JavaScriptu

1. Model jednej wymówki jako obiektu.
2. Tablica obiektów z wymówkami.
3. Pobranie elementów HTML z DOM-u.
4. Funkcja wyświetlająca wymówkę.
5. Losowanie indeksu tablicy.
6. Obsługa kliknięcia przycisku.
7. Unikanie losowania tej samej wymówki dwa razy.
8. Kopiowanie tekstu do schowka i komunikat dla użytkownika.
9. Filtrowanie według kategorii.
10. Zapamiętywanie historii w `localStorage`.

## Struktura

- `index.html` — treść i semantyka strony,
- `style.css` — cały wygląd aplikacji,
- `script.js` — logika, którą będziemy budować krok po kroku.
